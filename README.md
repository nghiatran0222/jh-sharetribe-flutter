# Jh-sharetribe-flutter

## Assessment Requirements

Complete Flutter, API integration, authentication, and Sharetribe:

### 1. Sharetribe

- Set up a basic Sharetribe environment.
- Implement a simple transaction flow.
- Make a change to the transaction process and briefly explain your approach.

### 2. Flutter App

- Build a small Flutter application that authenticates with Sharetribe.
- Fetch and display listings from Sharetribe.
- The UI can be simple — we are primarily interested in the functionality and code structure.

### 3. Submission

- Source code for both the Sharetribe implementation and Flutter app.
- A short README with setup instructions.
- A brief explanation of the changes you made to the transaction process.
- You may use publicly available documentation and libraries as needed.

### 4. Timeline

- 3 days.
